## 🛠️ Tech Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Built With** | OpenAI Codex / GitHub Copilot | AI-assisted development |
| **AI Features** | OpenAI GPT-4o API | In-app AI intelligence |
| **Frontend** | React Native | Cross-platform mobile (Android & iOS) |
| **Language** | TypeScript | Type-safe JavaScript |
| **Navigation** | React Navigation | Screen management |
| **State Management** | Zustand | Global state handling |
| **Styling** | NativeWind (Tailwind for RN) | UI design system |
| **Backend** | Node.js + Express | REST API & business logic |
| **Database** | Firebase Firestore | Real-time cloud database |
| **Authentication** | Firebase Auth | Secure user accounts |
| **File Storage** | Firebase Storage | Media & uploads |
| **AI API Calls** | Axios | HTTP requests to OpenAI |
| **Environment** | dotenv | Secure API key management |
| **Deployment** | Google Play Store | Android distribution |
| **Version Control** | GitHub | Source control & portfolio |
